PhantomUI 0.9.32 - UI for Azeroth Survivors
==========================================

Install
-------
Unzip so the folder "PhantomUI" sits in your AddOns folder
(benilla-config/AddOns/PhantomUI/PhantomUI.toc). PhantomUI is a complete UI on its own:
disable SurvivorsDragonUi (or any other full UI addon) when you use it.
If you used CompactSCT or AZS Spell Meter before: both are now part of PhantomUI,
remove their old folders.

Commands
--------
/pui           settings window
/pui unlock    anchor mode (move & resize everything), /pui lock to finish
/pui reset     all frames back to the default layout
/csct          damage numbers settings
/azsm          damage meter (show, hide, reset, resetpos)

Everything is also reachable from the button bar under the minimap.
/plan          plan: pick abilities, necklace, rings and trinkets in order
