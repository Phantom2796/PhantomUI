Everything in one addon

Interface, minimap, damage meter and floating numbers share one style, one settings window and one anchor mode.

▣

Complete interface

Player and target frames, flush action bar, run timer with boss skulls, boss and guardian bars, XP bar, square minimap, game menu, nameplates.

◆

Alerts & run stats

Boss and guardian alerts small under the chat instead of big banners, and your run stats always visible next to the minimap – with the game's own tooltips.

◎

Retail-style buffs

Cooldown clock and countdown inside the icon, stacks in the corner, debuff borders in their type color, no blinking.

≡

Damage meter

Per-ability damage, DPS and share. Flip with the arrows between damage, boss damage only and healing. The right icon for every spell, proc and jewel in all languages.

✦

Floating numbers

Compact damage numbers with the spell icon above your enemies, red crits, merged hits and a minimum size so the screen stays readable.

❖

Ability & item plan

Click your abilities, necklace, rings and trinkets in the order you want them. Saved per class, shown during the run, taken abilities turn green; tooltips show each item's base effect.

✥

Anchor mode

Drag any frame, pull edges for width and height, the corner scales. A grid with black center lines and mirrored colors makes symmetric layouts easy.

✎

Clean chat

Transparent and movable, a modern font, a flat input line and old lines fade out after 10 seconds. Mouse wheel scrolls, Shift jumps to the top or bottom.

⚙

One settings window

/pui opens every option in tabs: textures, fonts, sizes, colors and an on/off switch for each part.

Install in a minute

PhantomUI is a complete UI on its own.

Download

Grab the zip from the download link – always the newest version.

Unzip

Place the PhantomUI folder in benilla-config/AddOns/.

Clean up

Disable SurvivorsDragonUi; delete old CompactSCT / AZS Spell Meter folders – they are built in now.

Play

Start the game and type /pui to make it yours.

Commands

Most things also sit on the button strip under the minimap.

/puisettings window
/pui unlock · /pui lockanchor mode on / off
/pui resetevery frame back to the default layout
/planability & item plan editor
/azsmdamage meter: show, hide, reset, resetpos
/csctfloating numbers settings

Good to know

 

Can the plan show up in the main menu?

No. The main menu is drawn by the game itself before the addon interface loads. Plan once with /plan during any run – it is saved per class and shows up in every run after that.

Can PhantomUI pick the level-up cards for me?

No. The choice cards are drawn by the game and there is no way for an addon to choose them. The plan window is there so you know at a glance what to take.

Where are my settings stored?

In benilla-config/saved/PhantomUI.lua. Updating the addon folder keeps them.

Something looks off after a game update?

Open an issue on GitHub with a screenshot – the addon reads the game's own data, so most updates need no change at all.
